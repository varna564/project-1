# Fairy AI Game🧚

A fun, interactive web-based game featuring a magical AI fairy companion.

## Features📌
* **Interactive Chat:** Communicate with the Fairy AI.
* **Mood System:** Change the fairy's mood and watch her respond.
* **Responsive Design:** Works across different devices.

## Files📁
* `index.html`: Main landing page and interface.
* `game.html`: Gameplay environment.
* `style.css`: Visual styling and layout.
* `script.js`: Game logic and AI interactions.

## How to Run🪄
Simply open `index.html` in your web browser to start playing!
